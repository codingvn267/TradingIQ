Project Overview
Trading IQ is an end-to-end trading platform designed to support technical trading and trading using AI. The project includes both frontend and backend components which provides users with market analysis, AI insights, market headlines and trade execution. 
Architecture 
The project has 2 main directories: 
-	Backend/Trading_IQ: I used Spring boot to build the backend. The backend handles all of the trading strategies, data processing, and communication with external services and database. 
-	Frontend/my-app: I used React to build the frontend. The frontend handles user interface, allowing users to interact with 2 different trading tools TA and AI, visualize the data by interactive candle charts, etc. 
Technologies Used
-	Backend: Spring Boot
-	Frontend: React, HTML, CSS
Potential Challenges Faced
-	Data integration: fetching and processing data from different APIs is time consuming since each has its own document which takes time to fully understand how it works. 
-	Security: I was trying to JWT for security but again it takes time to learn so I decided to just created a database of username and password for the project. 
-	Even though Spring Boot is a Java-based framework and I have practiced Java since I got into the program at St. Thomas, some concepts like beans, dependency injection, Restful APIs, etc. are still hard to learn. 
-	How to make the backend communicate to frontend effectively is also a time-consuming process, and it is new to me.
